Technical details
Protection level
OfflineSeal Web: browser-enforced. The browser's sandbox and Content Security Policy keep the processing tool off the network. It is not OS-level network isolation; that is what OfflineSeal Desktop provides.
Lifecycle
Tool downloaded → fingerprint verified → sealed frame created → frame checks its own seal → file accepted. Each new image gets a fresh frame.

Not covered by browser policy
WebRTC is not governed by CSP or the sandbox. The frame removes WebRTC before any other code runs, which is JavaScript-level hardening rather than a browser boundary. Browser extensions can see page content. See the project README for the full limits.
